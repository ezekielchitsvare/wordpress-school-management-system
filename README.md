# WordPress School Management System

A customized WordPress-based school management system deployed for a school in Zimbabwe.

## Overview

This project was built to help manage school operations including student administration, communication, records, and reporting.

The system was customized and deployed using WordPress and a commercial school management solution.

- Student management
- Administrative dashboard
